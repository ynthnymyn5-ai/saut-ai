# MMR media — put the brand's real photos and film here

Then run `npm run media` (needs ffmpeg). Files are resized, converted to WebP / MP4 + WebM and wired into the site automatically. Any slot left empty keeps the built-in 3D scene or illustration.

| File | Where it appears | Tips |
|---|---|---|
| `story.jpg` | Our Story, right half (full height) | Portrait or square, at least 1600 px wide. Hands, roasting, the bar. |
| `experience.mp4` (or `.mov`) | Full-width background of "More than a coffee" | 10–20 s, no talking needed (audio is removed), slow close-ups of pouring/crema. First 20 s are used. |
| `products/signature.jpg` | Product sheet for MMR Signature | Product on a dark background works best. |
| `products/velvet.jpg` | Product sheet for MMR Velvet | |
| `products/gold.jpg` | Product sheet for MMR Gold | |
| `products/coldbrew.jpg` | Product sheet for MMR Cold Brew | |
| `menu/<item>.jpg` | Menu row thumbnail + hover preview | English name in lowercase with dashes: `espresso`, `flat-white`, `spanish-latte`, `americano`, `ethiopian`, `colombian`, `al-raiba`, `egg-cheese`, `egg-mayo`, `halloumi-beetroot`, `four-cheese`, `full-halloumi`, `turkey`. Shot from above, centred (shown in a circle). |
