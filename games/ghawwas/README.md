# غوّاص اللولو (Ghawwas)

One-touch Gulf pearl-diving game starring Bu Lulu from «مور».
Drag left/right (or arrow keys) to steer the diver down the rope (السيب), collect oysters (🦪, golden = دانة ×5),
grab bubbles for air (النَفَس), avoid jellyfish and — after 20 fathoms (باع) — sharks (جرجور). Chains of pearls raise a multiplier up to ×5.

- `index.html` — built single-file game (images inlined), open in any browser.
- `template.html` — source; `{{lulu}}` / `{{face}}` are replaced with `assets/*.webp` as data URIs when building.
