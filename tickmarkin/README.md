# معهد تيك ماركن — Tickmarkin Institute

موقع كامل للمعهد بالعربية (RTL): صفحات تعريفية، كتالوج دورات بأربعة أقسام، نموذج تسجيل يحفظ الطلبات، نموذج تواصل، ولوحة إدارة محمية بكلمة مرور.

لا يحتاج أي مكتبات خارجية — Node.js 18 أو أحدث فقط.

## التشغيل

```bash
cd tickmarkin
ADMIN_PASSWORD='كلمة-مرور-قوية' npm start     # http://localhost:3000
npm test                                      # 9 اختبارات
```

إذا لم تضع `ADMIN_PASSWORD` تُولَّد كلمة مرور مؤقتة وتُطبع في سجل الخادم عند كل تشغيل.

## الصفحات

| الرابط | المحتوى |
|---|---|
| `/` | الرئيسية: البطل، الإحصائيات، الأقسام، الدورات المميزة، المزايا، خطوات التسجيل، المدربون، الآراء، الأسئلة الشائعة |
| `/courses` | كل الدورات مع تصفية حسب القسم وبحث (`?dept=tech&q=...`) |
| `/course?id=...` | تفاصيل دورة: المحاور، المدرب، المواعيد، الرسوم، دورات ذات صلة |
| `/departments` | الأقسام الأربعة ودورات كل قسم |
| `/about` | من نحن، الرؤية والرسالة، فريق المدربين |
| `/contact` | نموذج تواصل، بيانات الاتصال، الخريطة |
| `/register` | نموذج التسجيل (`?course=ielts` لاختيار دورة مسبقاً) |
| `/admin` | لوحة الإدارة: الطلبات، تغيير الحالة، البحث والتصفية، الحذف، تصدير CSV للإكسل، الرسائل |

## تعديل المحتوى

- **الدورات والأقسام والمدربون:** `data/courses.json` (العنوان، السعر، تاريخ البدء، الساعات، المحاور…).
- **الهيدر والفوتر (الهاتف، البريد، واتساب):** `partials/header.html` و `partials/footer.html`.
- **رقم واتساب** يظهر أيضاً في `public/js/main.js` و `public/contact.html` — ابحث عن `966500000000`.
- **الألوان:** المتغيرات في أعلى `public/css/style.css`.
- آراء المتدربين في الرئيسية نماذج توضيحية؛ استبدلها بآراء حقيقية.

## البيانات

الطلبات والرسائل تُحفظ في `data/db.json` (غير مرفوع إلى git). غيّر المسار بـ `DATA_FILE`.

## النشر

يحتاج خادماً بقرص دائم لأن البيانات تُحفظ في ملف: VPS، أو Render / Railway / Fly.io مع Volume.

متغيرات البيئة: `ADMIN_PASSWORD` (إلزامي في الإنتاج)، `PORT`، `DATA_FILE`، `NODE_ENV=production` (يفعّل Secure cookie)، `TRUST_PROXY=1` خلف بروكسي.

## الحماية

- كوكي جلسة HttpOnly + SameSite=Strict، ومقارنة كلمة المرور بزمن ثابت، وحدّ لمحاولات الدخول.
- رفض الطلبات القادمة من نطاقات أخرى (CSRF)، وحدّ لعدد الإرسالات لكل IP، وحقل مخفي لاصطياد البوتات.
- التحقق من كل المدخلات على الخادم، وعرضها في لوحة الإدارة كنص فقط (بدون XSS).
- حماية ملف CSV من حقن الصيغ، وترويسات أمان (CSP و X-Frame-Options و nosniff)، ومنع الوصول للملفات خارج `public/`.
